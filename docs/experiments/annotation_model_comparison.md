## 5. 归一化口径（**只用于比较**）

- 展示与落盘一律保留**模型原始输出**；只有比较时才归一化，避免"做多 vs LONG"
  这类同义不同写被误判成分歧。
- 方向：`做多/看多/多单/bullish/long` → `LONG`；`做空/看空/空单/bearish/short` → `SHORT`；
  `观望/中性/震荡/flat/neutral` → `FLAT`；`未知/无法判断/不适用` → `UNKNOWN`。
- 周期：`15分钟/超短` → `15M`；`半小时/30分钟` → `30M`；`日内/短线/1小时` → `1H`；
  `4小时/半天` → `4H`；`日线/中线/本周/波段` → `1D`。
- 信息类型：`宏观/基本面` → `MACRO`；`技术面` → `TECHNICAL`；`消息/新闻` → `NEWS`；
  `情绪` → `SENTIMENT`；`持仓/资金流` → `POSITIONING`；`其他` → `OTHER`。
- 止损/目标位：取第一个数值（`2,450`→`2450`、`≈2340`→`2340`、`2340-2350`→`2340`）；
  空白与 `-` / `N/A` / `None` / `无` 一律视为**未给出**。
