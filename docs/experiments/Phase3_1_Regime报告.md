# Phase 3.1 Market Regime 机器验收报告

日期：2026-09-18

状态：**BLOCKED（机器覆盖率失败，未正式写库）**

## 1. 实现口径

- 模型版本：`regime-rules-stat-v1`；首版只允许 XAUUSD 1h。
- 规则层：EMA20/60 与 4 根斜率、ADX14、ATR14/close 的因果滚动 60 期分位。
- 统计校验层：波动分位 + ATR 标准化趋势距离，只使用当前及历史数据。
- 状态优先级：数据不足 → 新闻驱动 → 高波动 → 趋势 → 低波动/区间。
- 新闻驱动预注册阈值：近 4h 至少 3 条新闻或 1 条宏观发布；事件还必须满足
  `effective_at <= as_of`。
- 防抖：最短持有 12 根，候选新状态连续确认 3 根后切换。
- 缺口：CME 周末与每日结算休市保留连续性；其他缺口重置指标成熟窗口，不插值、不缩窗。

## 2. 真实库 dry-run

输入：XAUUSD（实际 provider 为 `GC=F` 连续期货代理）1h，11,317 根，37 个严格连续段。

| 指标 | 结果 | 门槛 | 判定 |
|---|---:|---:|---|
| UNKNOWN | 1,768 / 11,317 = **15.62%** | ≤1% | **FAIL** |
| 平均状态持续 | 19.69 根 | ≥12 根 | PASS |
| 单日最大切换 | 2 次 | ≤6 次 | PASS |
| 规则/统计一致率 | 92.46% | ≥80% | PASS |
| 时间因果违规 | 0 | 0 | PASS |

状态分布：RANGE 3,469、HIGH_VOLATILITY 2,170、TREND_UP 1,587、
TREND_DOWN 1,193、LOW_VOLATILITY 1,130、UNKNOWN 1,768、NEWS_DRIVEN 0。

NEWS_DRIVEN 为 0 是符合时间因果的结果：当前新闻与宏观回填的 `effective_at` 晚于
行情评估时点，不能倒填成当时已知事件。

## 3. 失败根因

W0-1 provider 审计已确认 XAUUSD 1h 有 242 个异常槽：105 个 `data_gap`、137 个
`missing_timestamp`。EMA60 与 ATR 分位需要完整回溯窗口，因此每个异常簇之后都必须重新成熟，
不能跨缺口或用插值伪造连续历史。由此产生 15.62% UNKNOWN；这是输入质量门禁生效，
不是通过调整分类阈值可以修复的问题。

## 4. 已落地的安全措施

- 默认 dry-run；机器门禁任一失败时，`--no-dry-run` 返回失败并拒绝写 `market_regimes`。
- 未来 K 线注入不会改变历史结果；未来才生效的事件不会触发 NEWS_DRIVEN。
- 异常缺口后指标重新成熟；快照时间链要求 `max_effective_at <= as_of <= detected_at`。
- 已生成 50 点盲评表 `logs/phase3_1_regime_blind_review.csv`，答案键单独保存；但在数据门禁
  修复前，人工抽检不能替代机器覆盖率失败。
- 验证结果：专项 Regime/W0-5 测试 10 passed；全量 2536 passed / 1 skipped；
  `ruff check .` 与 `mypy config database src scripts`（93 个源文件）通过。
