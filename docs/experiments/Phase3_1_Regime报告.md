# Phase 3.1 Market Regime 验收报告

日期：2026-09-18

状态：**机器验收 PASS；等待 50 点人工盲评后最终验收**

## 1. 实现口径

- 模型版本：`regime-rules-stat-v1`；首版只允许 1h。
- 规则层：EMA20/60 与 4 根斜率、ADX14、ATR14/close 的因果滚动 60 期分位。
- 统计校验层：波动分位 + ATR 标准化趋势距离，只使用当前及历史数据。
- 状态优先级：数据不足 → 新闻驱动 → 高波动 → 趋势 → 低波动/区间。
- 新闻驱动阈值：近 4h 至少 3 条新闻或 1 条宏观发布；事件必须满足
  `effective_at <= as_of`。
- 防抖：最短持有 12 根，候选新状态连续确认 3 根后切换。
- 缺口：正常周末、每日结算和已知黄金市场节假日休市保留连续性；其他缺口重置指标成熟窗口，
  不插值、不缩窗。

## 2. 第一轮受阻：Yahoo `GC=F` 期货代理

原 XAUUSD 记录实际是 Yahoo `GC=F` 连续期货代理。11,317 根 1h K 线被 242 个异常槽切成
37 段，导致 `UNKNOWN=1,768/11,317=15.62%`，高于 ≤1% 门槛。CLI 因此拒绝写库，
该轮没有生成正式 Regime。

## 3. 第二来源采集与隔离

- 新增独立标的 `XAUUSD_DUKASCOPY`，不修改、不覆盖，也不与 `GC=F` 逐根拼接。
- 来源：Dukascopy 官方 `datafeed` 的 XAUUSD 1 分钟 BID BI5 文件；2024-09-15 至
  2026-09-17 共 733 个日文件全部取得，格式错误 0。
- 原始文件保存在 gitignored 只追加目录，逐文件计算 SHA-256；只聚合恰好含 60 个连续分钟的
  小时桶，缺分钟拒绝，休市零量占位拒绝。
- 得到 11,872 根现货 1h K 线；首次入库 11,872，幂等复跑新增 0、重复 11,872。
- 新来源保持 `enabled=false`，只允许显式历史回填脚本运行，避免通用调度器误调用未注册采集器。
