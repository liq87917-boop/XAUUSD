## 5. 局限与下一步

1. **样本量**：探针刻意只取 1 年日线 / 2 年小时线，OOS 窗口数有限 → 任何 IC 都必须带 CI 与 q 值来读，**不得**用点估计下结论；
2. **多重检验**：8 特征 × 2 模型 × 多配置 → 已做 BH-FDR；**q > 0.05 一律视为「未证明」**；
3. **单标的**：只有 XAUUSD，不能外推成「技术面在黄金上有普遍预测力」的结论；
4. **无交易成本**：本探针只测「信号质量」，不测可交易性（成本与滑点属 Phase 4 回测）；
5. **不进 Phase 3 结论**：探针只用于决定「是否投入完整数据底座 + Regime」；若 IC 不显著，应优先考虑「换特征 / 扩样本」而不是上更复杂的模型（`.clinerules` 禁止 DL）。
6. **Brier 只在同类之间可比**：`random` 输出连续概率，而特征/`momentum`/`ma` 输出 0/1 判定 → 跨类比较 Brier 会误导（本条与上条同属口径限制，报告读者必读）。
